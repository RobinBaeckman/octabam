# machines (test remix)

Every machine on the machine table in one image: ANALOG BD, MINIMOOG (LADDER),
OCTA-303 and JUNO (POLY) on rows 5-8 of the track's machine list
([docs/contributing/MACHINES.md](../../../docs/contributing/MACHINES.md)).
SPRING REV is out: ANALOG BD's DSP voices sit in its words.

Gates: `verify_machines.py machines`, each machine's UI and voice gates, and
`OT_PROJECT=<dir> verify_poly_port.py machines` (a MIDI pattern with a chord
playing POLY end to end).

## Where it has run

Not flashed. Under the port only.
